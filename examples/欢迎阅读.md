# 欢迎使用简墨

简墨是一款轻巧、安静的 **Markdown 阅读工具**。

## 试一试

- 一次打开多份文档，用顶部标签切换
- 点击左侧大纲，跳到你感兴趣的章节
- 选择文件夹，在侧栏浏览 Markdown 文档
- 点击 Aa 调整字号，或切换深色主题

## 代码与表格

```python
from math import sqrt

def distance(x, y):
    return sqrt(x ** 2 + y ** 2)
```

| 功能 | 快捷键 |
